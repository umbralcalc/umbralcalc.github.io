# Introduction
<div style="height:0.75em;"></div>

The [Acting on Simulated Systems](https://umbralcalc.github.io/posts/acting_on_simulated_systems_introduction.html) collection showed simulations informing real-world decisions through interactive dashboards.

This collection asks the fundamental question that sits underneath all of those: once a simulation has suggested an action, how do we know whether to trust it?

Those who are unfamiliar with the simulation diagramming and terminology used throughout this collection will benefit from a review of the [Simulating Real-World Systems as a Programmer](https://umbralcalc.github.io/posts/simulating_real_world_systems_as_a_programmer_introduction.html) collection.

Those eager to follow along with code should also check out the [stochadex project](https://stochadex.github.io/), which was used to create the simulations which power these dashboards.
